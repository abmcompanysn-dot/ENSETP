# ENSETP — Dîner de Gala de Fin d'Année 2026

Plateforme web officielle du **Dîner de Gala de Fin d'Année ENSETP 2026**

**Samedi 20 Juin 2026 · Au Magic Land · Dakar**

---

## Fonctionnalités

- Achat de tickets en ligne (Solo 1 000 FCFA / Couple 2 000 FCFA)
- Paiement via Wave, Orange Money, Free Money, Carte bancaire (Paydunia)
- Génération de tickets PDF avec QR Code unique
- Confirmation de présence pour les détenteurs de tickets
- Panel Admin sécurisé (5 onglets : Tableau · Commandes · Présences · Équipe · Config)
- Délégation d'admins avec gestion des rôles
- Likes & commentaires par artiste
- Rapport quotidien par e-mail
